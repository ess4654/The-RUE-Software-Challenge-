SERIAL KNOCKOUT PROTOCOL — One at a Time, Observe, Map
==========================================================

STEP 1: BASELINE DOCUMENTATION
— Full body photography (every region, standardized lighting)
— Hair density count per cm² for each of the four regions (scalp, body, pubic, beard)
— Follicle biopsy samples (archived) from all four region types
— Bloodwork: full metabolic panel, hormone panel, immune markers
— Pre-existing conditions documented (any folliculitis, acne, etc.)

STEP 2: TARGET PRIORITIZATION
— Rank the four candidate gene targets by predicted specificity
— Best candidate = gene expressed in ONLY one hair type, no known critical pleiotropy
— Worst candidate = gene expressed in multiple hair types or other critical tissue
— Start with the cleanest target first — minimize risk, maximize learn rate

STEP 3: KNOCKOUT #1
— Deliver CRISPR RNP via LNP (leading delivery candidate)
— Target: Gene A (highest specificity candidate)
— Delivery method: topical LNP application to full body surface OR regional injection
— Wait 4-6 weeks
— OBSERVE AND RECORD:
  [ ] Which hair group stopped growing?
  [ ] Did ANY other hair group change?
  [ ] Did any non-hair tissue change? (skin texture, sweat, nails, vision, hearing)
  [ ] Bloodwork at 2 weeks, 4 weeks, 6 weeks
  [ ] Photography comparison

STEP 4: MAP RESULT
— If Gene A knockout killed Hair Type X only → CONFIRMED MAP: Gene A → Type X
— If Gene A knockout killed multiple types → partial pleiotropy detected, document
— If Gene A knockout killed nothing → wrong target, reassess, next candidate

STEP 5: KNOCKOUT #2
— Only proceed if Step 3 showed clean result with no adverse effects
— Target: Gene B (second-highest specificity)
— Same delivery, same observation protocol
— Wait 4-6 weeks, full documentation

STEP 6: MAP RESULT
— Same mapping protocol as Step 4

RISKS AND CONTINGENCIES
==========================================================

RISK: Gene knockout affects non-hair tissue
MITIGATION: Sequential approach means you STOP after any adverse result. You never proceed to the next knockout until the current one is confirmed safe.

RISK: Immune reaction to Cas9 protein
MITIGATION: Use RNP (degrades in 24-48 hours), not viral. Monitor bloodwork for cytokine elevations. Have corticosteroid protocol ready.

RISK: LNP delivery doesn't reach follicle bulge stem cells
MITIGATION: If topical fails, escalate to intradermal microinjection. If that fails, try electroporation-assisted delivery.

RISK: Hair regrows after knockout (stem cells survived)
MITIGATION: Wait full 6 weeks before calling success or failure. Follicles cycle. If regrowth occurs, second dose to same target. You only advance to next gene when current gene is CONFIRMED DEAD.

RISK: Complete baldness causes social/psychological impact
MITIGATION: Operator has pre-declared acceptance. Document psychological state at each interval. Offer support resources. This was a fully informed choice.
