% ===================== UFO SHAPE GLYPHS =====================
% Line-drawn silhouettes for the shape taxonomy in Chapter 4. These are
% diagrams, not photographs, and deliberately so: a shape class is a
% geometry, and a drawing states the geometry without smuggling in a
% claimed sighting. Each glyph is set inside \shapeglyph, which fixes the
% canvas at 1.6in by 1.0in so every card in the run is identical.

  #1
  \end{tikzpicture}}
